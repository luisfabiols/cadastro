# 📋 Cadastro de Candidato

Projeto desenvolvido para criar um formulário de cadastro de candidato utilizando **HTML** e **PHP**.

O sistema permite que o usuário informe seus dados pessoais e profissionais. As informações enviadas pelo formulário são recebidas, processadas e apresentadas pelo arquivo PHP.

---

## 🎯 Objetivo

Desenvolver um formulário HTML capaz de coletar informações de um candidato e utilizar PHP para **receber, armazenar e apresentar os dados enviados**.

---

## 📝 Formulário

O arquivo `cadastro.html` contém um formulário com os seguintes campos:

* 👤 Nome completo
* 🎂 Idade
* 💼 Profissão
* 💰 Salário pretendido
* 📄 Experiência anterior---

## ⚙️ Processamento

O arquivo `processaCadastro.php` é responsável por:

1. Receber os dados enviados pelo formulário;
2. Processar as informações;
3. Armazenar os dados;
4. Apresentar os dados cadastrados.
